# Credits - monsters-other sound group

All clips in this folder were excerpted from the third-party sources below, edited (excerpted, trimmed, filtered, level-normalised, converted to mono 44.1 kHz Ogg Vorbis; some pitch-shifted or layered as noted) and re-encoded. Licences were checked on the asset's own listing/metadata (SoundBible listing, Internet Archive item metadata, Wikimedia Commons file page and wikitext, Kenney pack License.txt); Gravity Sound's CC BY 4.0 grant was additionally confirmed on an archived copy of its own site (web.archive.org, 2019-12-28) because the live page has since been removed. Only CC0 / public-domain / CC BY 3.0 / CC BY 4.0 material is included.
